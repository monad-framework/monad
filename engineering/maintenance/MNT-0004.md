# MNT-0004 — EOS event ledger is not merge-safe across divergent append histories

**State:** CLOSED

## Type

bug

## Summary

EOS event ledger is not merge-safe across divergent append histories

## Context

A merge of main into eosp/ai-driven-engineering-operating-model preserved CR-0003 canonical and registry state but silently removed its previously committed ENTITY_CREATED, STATE_TRANSITION, and DECISION_RECORDED events from .eos/events.jsonl. This broke lifecycle reconstructability until the exact historical events were recovered from Git. Required invariant: merge, synchronization, and reconciliation MUST NOT silently remove a previously recorded valid EOS event. Event reconciliation should preserve immutable events by event_id, fail closed on conflicting payloads for the same event_id, and verify lifecycle reconstruction after merge.

## Risk if Deferred

Leaving MNT-0004 open would create two maintenance records that appear to own the same defect, fragmenting planning, traceability, and eventual closure evidence. MNT-0003 is the original record and remains the authoritative maintenance owner for this defect.

## Proposed Resolution

Close MNT-0004 as an accidentally created duplicate. Retain its lifecycle and event history for auditability. Continue all investigation, planning, implementation, verification, and closure of the underlying event-ledger merge-safety defect under MNT-0003 only.
