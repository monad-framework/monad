# Working With ChatGPT and Codex

## Human

Sets direction, priorities, risk acceptance, authorization, and final acceptance.

## ChatGPT

Architecture, specification, decomposition, planning, governance, cross-artifact consistency, review, and coordination.

## Codex

Repository inspection, bounded implementation, refactoring, tests, mechanical changes, and local verification inside an authorized Work Packet.

## GitHub

Durable source/history, Issue/Project coordination, pull-request review, CI evidence, and releases.

## Rule

AI agents do not silently create authority. A Codex implementation task should be driven by a Ready and explicitly authorized Work Packet with clear governing artifacts, permitted scope, prohibited changes, acceptance criteria, and validation commands.
