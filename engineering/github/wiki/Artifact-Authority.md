# Artifact Authority

GitHub Issues, Projects, Wiki pages, generated machine companions, and `.eos/` control state are projections over canonical engineering artifacts.

A simplified authority direction is:

Constitutional/governing authority → Accepted ADRs → Approved specifications → Approved engineering plans/Work Packets → implementation/evidence → generated/projection material → journal/commentary.

When a projection conflicts with canonical authority, surface and reconcile the contradiction. Do not silently pick the convenient copy.

Architecture Decision Records live canonically under `architecture/decisions/`. The former root `adrs/` path is retired.
