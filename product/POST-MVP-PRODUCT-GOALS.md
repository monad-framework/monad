# Post-MVP Product Goals

**Status:** Approved forecast baseline under CR-0002

These goals follow `PG-001 — MVP Release 1`. They are product outcomes, not permission to implement all forecast backlog items.

## PG-002 — Living Workspace Intelligence

Monad can maintain explainable engineering memory, measure workspace intelligence and health, coordinate bounded agents through governed context, and improve future reasoning/execution from accepted evidence without converting probabilistic output into canonical truth.

### Evidence of achievement

- intelligence score and maturity tier are reproducible and explainable;
- canonical/derived/proposed/uncertain/stale/contradictory memory states are explicit;
- health/staleness/decay indicators identify problematic knowledge without inventing deletion policy;
- multi-vector memory and caches preserve isolation/provenance/invalidation;
- agent orchestration follows explicit dependencies and bounded authority;
- progressive autonomy can be promoted and demoted from evidence;
- independent reviewers and provider routing retain provenance and disagreements;
- automation/PR outcomes create durable evidence rather than hidden state.

## PG-003 — Governed Autonomous Engineering

Monad can coordinate progressively autonomous agents, integrations, and automation under declarative policy, independent review, signed attestations, strong identity/security boundaries, formal change control, audit, and operational observability.

### Evidence of achievement

- consequential changes can require valid DSSE-compatible attestations;
- cryptographic profiles can rotate and include post-quantum migration paths;
- privileged/shared surfaces use governed RBAC/passkey identity where applicable;
- prompt injection, secrets, and capability escalation are explicitly defended;
- policy controls readiness, done, autonomy, compliance, and governed resources;
- change/rollback/restore and tamper-evident audit reconstruct consequential history;
- OpenTelemetry and execution analytics correlate actions to Work Packets/evidence;
- optional hosted analytics remain privacy-governed and separable from local core.

## PG-004 — Enterprise Ecosystem and Scale

Monad can deploy locally, air-gapped, on-premises, or in optional clouds; clone and restore governed workspaces; expose MCP/IDE/plugin/storage integration surfaces; and scale deterministic internal execution under measured performance and isolation profiles.

### Evidence of achievement

- approved shared surfaces can deploy with access controls/custom domains while local core remains independent;
- complete governed workspace state can be cloned/restored with provenance;
- air-gapped/no-exfiltration and on-prem/cloud profiles are explicit and testable;
- Docker/Nix environment profiles reproduce required execution/validation behavior;
- governed file/media handling preserves classification/provenance/AI-processing policy;
- MCP and LSP/IDE clients can inspect/query/explain/context without redefining truth;
- plugin/registry/pack and graph/vector storage contracts are versioned and isolated;
- optional external runtime profiles, including EVM where implemented, remain adapter-scoped;
- parallel execution preserves deterministic state/evidence ordering;
- scale benchmarks and local state-finalization targets have declared reference profiles and acceptance evidence;
- Release 2 acceptance proves migration from the MVP baseline without weakening PG-001 guarantees.
