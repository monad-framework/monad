# Publication Specifications

This directory contains normative specifications governing projections of Monad's canonical engineering knowledge into external publication and documentation surfaces.

## Specifications

| ID | Title | Status |
| --- | --- | --- |
| `MONAD-PUB-001` | Publication Projection Contract | Draft |

## Authority

The specifications in this directory define publication behavior and constraints.

Implementation configuration under `publication/` SHALL conform to these specifications.

The publication configuration, generated website state, synchronization automation, and downstream website repository are projections and SHALL NOT supersede the canonical engineering knowledge governed by Monad.
